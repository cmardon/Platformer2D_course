# Cours : Création d'un Platformer en 2D avec Godot

## 1. Installation

| Étape | Description |
|-------|-------------|
| 1 | Une fois **Godot** ouvert, importer le projet en cliquant sur le bouton `Importer`, sélectionner le dossier `Platformer2D_course`, double cliquer sur `project.godot` et valider en cliquant sur `importer`|

(Autre méthode: cliquer sur scanner, choisir le dossier *Téléchargements* et valider).
Le projet devrait apparaître dans la fenêtre **Godot**.
